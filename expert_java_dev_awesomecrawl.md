<crawling-strategy>
1. Fetch the latest stories listing from https://spodeli.net/ (first 20 stories)
2. Extract story IDs from the listing page links
3. Query the database for which of these story IDs already exist
4. For each new story ID:
   - Fetch the individual story page
   - Parse title, content, views
   - Insert into PostgreSQL with created_at = now()
5. Paginate if needed: if all 20 stories on a page are new, fetch the next page
   (/index-story/20/, /index-story/40/, etc.) until hitting known stories
6. Stop when a page contains only already-scraped stories
7. Add polite delay between HTTP requests (1-2 seconds)
</crawling-strategy>
